# 숫자 발굴 — 주사위 3개로 블럭을 캐는 연산 게임

보드게임 **파라오코드**의 규칙을 바탕으로 만든 수업용 연산 게임입니다.
설치·가입 없이 브라우저에서 바로 쓰고, 서버 없이 **시드** 하나로 반 전체가 같은 문제를 풉니다.

**바로 사용:** https://pharaoh-code-omega.vercel.app

![게임 화면](docs/screenshot.png)

## 왜 만들었나

보드게임은 한 세트로 4명뿐이라 30명 교실엔 세트가 여럿 필요하고, 웹 교육 게임은 가입·유료 전환·학교 네트워크 차단에 걸리기 일쑤입니다. 무엇보다 선택지에서 고르는 방식은 학생이 찍기 시작하면 연산 연습이 되지 않습니다.

그래서 조건을 네 가지로 잡았습니다.

- 설치와 가입이 없을 것
- 서버에 의존하지 않을 것
- 전원이 같은 조건에서 겨룰 것
- 찍기가 통하지 않을 것

## 규칙

- 블럭 15개가 5층 피라미드로 놓입니다 (1·2·3·4·5개). 위로 갈수록 큰 수, 높은 점수
  - 아랫줄: 1~12, 1~3점 / 윗줄: 70~96, 15~26점
- 주사위 3개를 굴려, 나온 세 수를 **전부 한 번씩** 써서 블럭 숫자를 만들면 획득
- 나눗셈은 나누어떨어질 때만, 중간 결과도 정수만 (음수는 허용)

| 모드 | 연산 |
|---|---|
| 사칙연산 | + − × ÷ |
| 확장 | + − × ÷ 팩토리얼(!) 제곱근(√) 조합(C) 거듭제곱(², ³) |

예) 6, 2, 2로 12 → (6−2)! ÷ 2 = 24 ÷ 2 = 12
예) 5, 6, 6으로 14 → 5! ÷ 6 − 6 = 20 − 6 = 14

## 찍기가 안 되는 이유

블럭을 고르면 주사위 세 수가 칩으로 뜨고, 칩과 연산을 번갈아 눌러 **학생이 직접 식을 조립**합니다. 마지막 값이 목표와 같아야 획득되고, 프로그램은 맞는지만 확인할 뿐 풀이를 알려주지 않습니다.

규칙 설명용으로 풀이를 보여주는 **연습 모드**가 따로 있습니다. 블럭을 누르면 계산 과정이 단계별로 뜨지만, 15칸 중 평균 9칸이 정답이라 찍어도 점수가 나오니 경쟁에는 쓰지 마세요.

## 수업에서 쓰기

1. 시작 화면에서 **시드**(숫자)와 **제한 시간**(2·3·5분)을 정합니다
2. 칠판에 시드를 적고 전원 같은 값으로 시작 → 블럭 배치·점수·주사위 순서가 모두 동일
3. 각자 자기 화면에서 풀기 때문에 서버가 없고, 한 명이 끊겨도 나머지는 그대로 진행
4. 시간이 끝나면 결과 화면: 점수, 가상 플레이어 분포 기준 백분위, **연산 내역**(사칙연산만 썼는지, 팩토리얼을 섞었는지 등)
5. **결과 복사** 버튼으로 "이름, 점수, 시드"가 한 줄로 복사됩니다 → 구글 폼이나 학급 채팅방에 붙이게 하면 수합 끝

운영 팁
- 시드마다 편차가 있어서(윗줄이 초반에 전혀 안 열리는 판도 있음) 수업용 시드는 미리 한 번 돌려보고 고르세요
- 확장 모드는 조합이 들어가므로 확률과 통계를 배운 뒤가 적당합니다. 그 전엔 사칙연산 모드로
- 한 차시에 여러 판 돌리려면 3분이 적당합니다

## 구조

- `index.html` 단일 파일, 외부 서버 없음
- 시드 기반 난수로 판·주사위 생성 (같은 시드 → 같은 게임)
- 백분위는 실제 학생 데이터가 아니라 가상 플레이어 수천 명 시뮬레이션 분포
